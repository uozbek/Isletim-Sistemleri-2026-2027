# İşletim Sistemleri · 2026–2027

Bu depo, Sakarya Üniversitesi Bilgisayar ve Bilişim Bilimleri Fakültesi Bilişim Sistemleri ve Teknolojileri Bölümü öğrencileri için **İşletim Sistemleri** dersinin haftalık notlarını içerir. Notlar, derste ele alınan konuları tekrar etmek ve slaytlardaki kavramları, şekilleri ve kod örneklerini Türkçe açıklamalarla incelemek için yardımcı kaynak olarak hazırlanmıştır.
